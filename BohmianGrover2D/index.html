About the wave and gates

Each box labels an orthogonal logical mode built from four sine eigenmodes along each axis. Packets overlap, so the probability of a logical mode differs from probability inside its geometrical box.

The bit order is |x₁x₀y₁y₀⟩. Columns increase left to right; rows increase bottom to top. The initial mode is |0000⟩.

A = HHad⊗4
ℋA = πℏ(I − A)/(2T)

Preparation and forward mixing use exp(−iℋAt/ℏ); inverse mixing uses the opposite sign. Phase gates use exact mode-projector exponentials. These are ideal mode operations, rather than free-box propagation. The wave evolves unitarily at every instant.

Three standard Grover iterations give 96.1319% marked-mode probability. All gates and the wave hold still at checkpoints and when paused.
