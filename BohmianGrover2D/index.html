One Bohmian particle lives in a real hard-walled square. The two logical bits are encoded by left/right localization in x and bottom/top localization in y.

|00⟩ = ϕL(x)ϕB(y),   ϕL = (u1+u2)/√2

The simulation resets in the localized state |00⟩. The first operation visibly and numerically evolves it under the square-box Hamiltonian into the balanced search state A|00⟩, with 25% logical probability in every state. The diffuser is calibrated to this same physical mixer A.

Choose any of the four logical states as the marked result. Changing the target resets the run. The oracle applies an exact logical phase reflection to the selected spatial mode. The diffuser remains exposed as three separate operations: inverse mixing, a reference pulse on |00⟩, and forward mixing.

D = A S00A†,   A = exp(-iHboxτ/ℏ)

This version applies the inverse mixer by reversing the sign of Hbox for τ, instead of waiting forward for 3τ. This is a numerical shortcut; particle guidance reverses with the wave.

The bright dots are an equilibrium ensemble of separate one-particle runs. The wave evolves on a GPU grid; the dots follow v = j/|ψ|².

The smooth colored arrows show the guiding direction for the most recent mixing Hamiltonian: along ∇S for forward mixing, opposite to it for inverse mixing. Both length and thickness increase with |∇S|. Each arrow uses the complementary hue of the local phase so it remains visible over the wave. Arrows fade near nodes, where phase is undefined and numerical division by very small density would be misleading.

v = ±(ℏ/m)∇S,   ψ = |ψ|eiS

The oracle and reference operations use the exact projector gate Uq(θ) = I + (e−iθ−1)|q⟩⟨q| on the numerical spatial wave. This makes every target equivalent. Particle positions are held fixed during the animated gate; the following interference and motion are generated by numerical Schrödinger evolution.

Rainbow hue shows the full phase arg(ψ), including global phase rotation. No reference phase is subtracted. Brightness still carries density, so true nodes remain dim; no phase angle itself is assigned black.

Time advances only while an operation is running. Between button presses the numerical wave and Bohmian particle ensemble are held at the completed checkpoint, so arbitrary user delay cannot change the algorithm.

This is a two-qubit educational search demonstration, not a scalable quantum-computer architecture.
